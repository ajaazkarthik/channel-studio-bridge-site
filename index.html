Channel Studio Bridge is a private Mac-based workflow for preparing, uploading, scheduling and verifying videos on YouTube channels that the operator owns or is authorized to manage.

How we handle dataUsage and limitations

No public registration. No hosted OAuth database. No paid publishing service.

What the application does

The account owner chooses a channel and explicitly approves actions. The software confirms the channel identity before using authorized YouTube API Services.

01

Prepare

Arrange local video files, thumbnails, subtitles, descriptions and publication schedules.

02

Upload and schedule

Send owner-authorized uploads and metadata to YouTube using Google OAuth permissions.

03

Verify and report

Check upload processing, visibility, channel identity, comments when requested, and performance analytics.

Privacy by design

Tokens remain on the Mac.

The local application stores OAuth access and refresh tokens in a restricted application-support folder. This public website exists solely to explain the software and its data practices. It never receives passwords, OAuth tokens or media uploads.

Questions

Who can use this?

The operator and explicitly authorized collaborators. Visitors cannot use this site to connect accounts or upload content.

What is sent to YouTube?

Only content and metadata that an authorized operator selects for upload, along with the requests necessary to manage or verify that content.

Can access be revoked?

Yes. Visit Google Account connections to revoke the application’s Google access, then remove the locally stored authorization files.
