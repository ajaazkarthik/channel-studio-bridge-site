# Channel Studio Bridge — Public OAuth information site

This repository contains only the static public website explaining the private, owner-operated Mac YouTube publishing workflow. It contains **no OAuth client secret, refresh tokens, source code for the private uploader, cookies, account identifiers, video files or API credentials.**

The [privacy policy](privacy.html) explains the tool's use of Google user data. The [terms of use](terms.html) describe operator responsibilities and YouTube policy compliance.

Published through GitHub Pages (free). The uploader itself remains private on the operator's Mac. Google OAuth uses a localhost callback; this site is the required public home/privacy information, not an OAuth callback endpoint.

No commercial hosted service, no public registration, and no affiliate advertising on this site.
